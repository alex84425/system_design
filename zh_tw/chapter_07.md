# 第 7 章：分散式唯一 ID 產生器（加強版）

## 1. 需求拆解

- 全域唯一
- 高吞吐
- 最好可排序（時間近似遞增）
- 多機房可用

## 2. 方案比較

### DB 自增

- 優點：簡單。
- 缺點：中心化瓶頸、跨區困難。

### UUID

- 優點：去中心化。
- 缺點：長度大、索引局部性差。

### Segment（號段）

- 優點：效能好、實作成熟。
- 缺點：依賴中心服務分配號段。

### Snowflake

- 優點：高吞吐、可排序、無中心熱點。
- 缺點：需處理時鐘回撥與機器 ID 管理。

## 3. Snowflake 關鍵細節

- 位元分配會影響壽命與每秒容量。
- 時鐘回撥要有保護：阻塞、告警、切換節點。
- 機器 ID 需唯一且可自動回收。
