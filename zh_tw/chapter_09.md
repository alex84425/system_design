# 第 9 章：網路爬蟲（加強版）

## 1. 目標

高效率抓取、低重複、對目標網站友善，並可持續增量更新。

## 2. 核心元件

- URL Frontier（排程佇列）
- Downloader（抓取器）
- Parser（解析器）
- 去重系統（URL 指紋）
- 儲存與索引

## 3. 關鍵策略

- robots.txt 與網域限速
- 重試退避與死信佇列
- 內容去重（Bloom Filter / 哈希）
- 依網站權重與更新頻率排程

## 4. 可擴展設計

- Frontier 分片 + 多 worker
- 非同步管線提升吞吐
- 增量抓取只抓變更頁面
- 觀測指標：抓取成功率、重複率、延遲
