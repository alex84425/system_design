核心差異（第一性原理）
TCP 和 UDP 的根本差別只有一件事：
TCP 在乎「資料有沒有完整送達」，UDP 不在乎
從這個出發，其他特性都是衍生的：
TCPUDP連線建立需要握手直接送順序保證✅❌重傳機制✅ 掉包會重送❌ 掉了就掉了速度較慢較快overhead大小

正確場景判斷邏輯

「掉一個封包，整件事會壞掉嗎？」

加密跟 TCP/UDP 無關，加密是 L7（TLS）的事，TCP 和 UDP 都可以加密。QUIC 就是 UDP + 自帶加密。
檔案傳輸反而要用 TCP，因為檔案不能少一個 byte，掉包就壞掉，所以需要重傳保證。

會 → TCP：檔案傳輸、網頁、API、Email
不會（或來不及重傳）→ UDP：直播、線上遊戲、語音通話、DNS query
