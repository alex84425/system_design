# 帕洛瑪　Paloma

**基酒**：龍舌蘭　**手法**：直接建構 build　**杯型**：高球杯　**風味**：酸／苦／氣泡

## 材料

- 龍舌蘭 50ml
- 葡萄柚汽水 100ml
- 新鮮萊姆汁 15ml
- 鹽少許

**裝飾**：葡萄柚片與鹽口

## 說明

在墨西哥本地，帕洛瑪比瑪格麗特更常見，是真正的國民日常飲品。葡萄柚的微苦與龍舌蘭的植物性意外地契合，加上一撮鹽能同時壓苦提甜。傳統用 Squirt 或 Jarritos 這類墨西哥葡萄柚汽水，講究一點的酒吧會改用現榨葡萄柚汁加蘇打水與糖漿自行組合，風味清亮許多。比瑪格麗特容易做得多，也更解渴，適合炎熱天氣。
