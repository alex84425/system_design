# 古典雞尾酒　Old Fashioned

**基酒**：波本威士忌　**手法**：直接建構 build　**杯型**：古典杯　**風味**：甜／辛香／溫潤

## 材料

- 波本或裸麥威士忌 45ml
- 方糖 1 顆
- 安格式苦精 2 dash
- 水少許

**裝飾**：橙皮

## 說明

調酒這個詞最原始的定義：烈酒、糖、水、苦精四樣東西的組合。十九世紀中期，當新式調酒越出越花俏時，老派客人會說「給我來杯老派做法的」，酒名就是這樣來的。做法是先把方糖用苦精浸濕、加一點水搗散，再分次加入威士忌與冰塊逐步攪拌稀釋。分次加冰是關鍵，一次倒滿會稀釋不均。整顆大冰球能減緩融化速度，讓最後幾口不會變成水。不要放水果丁下去搗——那是美國禁酒令後的墮落版本，會讓酒變成果醬水。
