# 美式基調　Americano

**基酒**：金巴利　**手法**：直接建構 build　**杯型**：高球杯　**風味**：苦／氣泡／清爽

## 材料

- 金巴利 30ml
- 甜香艾酒 30ml
- 蘇打水適量

**裝飾**：橙片

## 說明

內格羅尼的前身，也是它的低酒精版本——把琴酒換成蘇打水即可。1860 年代米蘭的 Caffè Campari 首創，原名 Milano-Torino，因為金巴利來自米蘭、香艾酒來自杜林。後來因美國觀光客特別愛點而改名。007 系列小說裡，龐德喝的第一杯酒就是美式基調。直接在杯中建構，不需要搖盪或攪拌，是入門苦味酒最溫和的選擇，酒精度大約只有內格羅尼的三分之一。
