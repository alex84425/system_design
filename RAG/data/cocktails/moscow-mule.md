# 莫斯科騾子　Moscow Mule

**基酒**：伏特加　**手法**：直接建構 build　**杯型**：銅杯　**風味**：辛香／氣泡／清爽

## 材料

- 伏特加 45ml
- 新鮮萊姆汁 10ml
- 薑汁啤酒 120ml

**裝飾**：萊姆角

## 說明

1941 年洛杉磯，一個賣不掉伏特加的酒商、一個賣不掉薑汁啤酒的餐廳老闆，加上一個有一堆銅杯庫存的人，三方聯手促銷的產物。這杯酒幾乎單槍匹馬把伏特加帶進了美國市場。銅杯不只是行銷噱頭——金屬導熱快，能讓杯壁迅速結霜，入口更冰冽。薑汁啤酒（ginger beer）與薑汁汽水（ginger ale）是兩種東西，前者經發酵、薑味濃烈辛辣，用後者會做出一杯乏味的酒。換成蘭姆酒是 Dark 'n' Stormy，換成龍舌蘭是 Mexican Mule。
