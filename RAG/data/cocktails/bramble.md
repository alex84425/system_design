# 黑莓　Bramble

**基酒**：琴酒　**手法**：直接建構 build　**杯型**：古典杯　**風味**：酸／果香／甜

## 材料

- 琴酒 40ml
- 新鮮檸檬汁 15ml
- 糖漿 10ml
- 黑莓利口酒 15ml

**裝飾**：黑莓與檸檬片

## 說明

1980 年代由倫敦的 Dick Bradsell 創作，他也是濃縮咖啡馬丁尼的作者。靈感來自他童年在英國鄉間採黑莓的記憶，是少數有明確在地情感的現代經典。作法是先把琴酒、檸檬、糖漿倒在碎冰上攪拌，再讓黑莓利口酒（crème de mûre）從杯緣淋下，紫紅色會沿著碎冰縫隙緩緩滲下形成大理石紋路，這個視覺是刻意設計的。碎冰不可省略，用方冰會讓漸層效果完全消失。
