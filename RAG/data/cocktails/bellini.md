# 貝里尼　Bellini

**基酒**：普羅賽克　**手法**：直接建構 build　**杯型**：笛型香檳杯　**風味**：甜／果香／氣泡

## 材料

- 普羅賽克氣泡酒 100ml
- 白桃果泥 50ml

**裝飾**：無

## 說明

1948 年由威尼斯 Harry's Bar 的 Giuseppe Cipriani 創作，粉橘色澤讓他想起文藝復興畫家 Giovanni Bellini 畫中聖袍的顏色。必須使用白桃而非黃桃——白桃的香氣細緻、酸度低，黃桃會過於濃烈且顏色偏橘。果泥要新鮮現打並冰鎮，罐頭桃泥的糖漿味會壓過氣泡酒。只能輕輕攪拌，過度攪動會讓氣泡散失。把白桃換成草莓是 Rossini，換成葡萄是 Puccini，都是同一間酒吧的延伸作品。
