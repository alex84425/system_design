# 艾普羅氣泡飲　Aperol Spritz

**基酒**：艾普羅　**手法**：直接建構 build　**杯型**：大酒杯　**風味**：苦／甜／氣泡

## 材料

- 普羅賽克氣泡酒 90ml
- 艾普羅 60ml
- 蘇打水 30ml

**裝飾**：橙片

## 說明

義大利威尼托地區的傍晚儀式，3-2-1 的比例好記到不需要量杯：三份氣泡酒、兩份艾普羅、一份蘇打水。艾普羅的酒精度只有 11%，苦度也遠低於金巴利，橙皮與大黃的味道偏甜，因此整杯清爽到接近軟性飲料，是夏日午後的標準配備。必須先放冰塊再倒液體，且氣泡酒先於艾普羅，否則較重的艾普羅會沉底不易混合。把艾普羅換成金巴利就是苦味明顯加重的 Campari Spritz。
