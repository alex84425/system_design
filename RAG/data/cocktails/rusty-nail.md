# 鏽釘　Rusty Nail

**基酒**：蘇格蘭威士忌　**手法**：直接建構 build　**杯型**：古典杯　**風味**：甜／草本／溫潤

## 材料

- 蘇格蘭調和威士忌 45ml
- 蜂蜜香甜酒 25ml

**裝飾**：檸檬皮

## 說明

只有兩樣材料，蘇格蘭威士忌加上 Drambuie 蜂蜜香甜酒，直接在杯中加冰建構。Drambuie 本身就是以蘇格蘭威士忌為基底、加入石楠花蜜與香料製成，所以這杯其實是同一種酒的兩種形態疊在一起，融合度天生就高。1960 年代因鼠黨（Rat Pack）成員愛喝而大紅。比例可依甜度偏好在 2:1 到 1:1 之間調整，冬天適合往甜的方向走。
