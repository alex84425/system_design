1. NG-SWG — Next Gen Secure Web Gateway（最核心）
做什麼： 監控所有 web 流量
你的瀏覽器 → Netskope → 任何網站

檢查你去哪些網站
Block 惡意網站
SSL inspection（decrypt HTTPS）


2. CASB — Cloud Access Security Broker
做什麼： 監控你用哪些 SaaS
你 → Netskope → Google Drive / Salesforce / Dropbox

你上傳了什麼檔案
有沒有違反 policy
防止資料外洩


3. ZTNA — Zero Trust Network Access
做什麼： 取代 VPN
員工（在家）→ Netskope → 公司內部系統

不信任任何人，每次都要驗證
Netskope Private Access 是唯一讓你完全退役 VPN 的方案 Career Guru99


4. DLP — Data Loss Prevention
做什麼： 防止敏感資料外洩
員工要上傳信用卡號碼到 Google Drive
→ Netskope DLP 偵測到
→ Block
Netskope 的 DLP 延伸到 web、SaaS、IaaS、private app、endpoint、甚至 email，是業界最全面的之一。 Quora

5. SD-WAN
做什麼： 管理公司分支機構的網絡
總部（香港）↔ 分公司（台北）↔ 分公司（新加坡）
Netskope 在 2022 年透過收購進入 SD-WAN 市場，目標是提供端到端的網絡和安全方案。 Quora

6. Cloud TAP
做什麼： Packet capture 工具
在 Netskope 私有雲環境捕獲封包，送給 NDR 或 NPM 等進階安全工具分析，支援 PCI DSS、HIPAA 等合規要求。 Career Guru99

7. Cloud Exchange
做什麼： 整合平台
把 Netskope 跟其他安全工具整合在一起，統一管理。 Software Testing Help
